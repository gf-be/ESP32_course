多传感器融合扩展板设计与精度提升算法实现
摘要
针对 MEMS 惯性传感器原始测量精度有限、易受零偏漂移、比例因子误差、安装误差和环境干扰影响等问题，本文设计并实现了一种基于 ESP32-WROOM-32 的多传感器融合扩展板。系统以自制 PCB 扩展板为硬件载体，集成 MPU6050 六轴惯性测量单元、HMC5883L 三轴磁力计以及BMP280 气压传感器，并预留 GPS UART 接口，用于构建可复现的姿态测量与传感器融合实验平台。硬件设计部分完成了系统需求分析、原理图设计、PCB 布局布线、信号完整性设计和测试点规划。算法部分围绕传感器误差建模与精度提升展开，设计了加速度计六位置标定、磁力计椭球拟合标定、陀螺仪零偏估计与 Allan 方差分析方法，并实现互补滤波、Madgwick/Mahony 滤波以及简化误差状态卡尔曼滤波。为进一步提升传感器信号质量，本文还设计了基于 1D-CNN 的 IMU 噪声去除方法，并与传统滤波方法进行对比。实验部分将围绕 PCB 实物调试、传感器标定效果、姿态估计精度、系统更新频率、功耗和成本等指标展开验证。实测结果显示，加速度计六位置标定后平均模长误差由 10.401 mg 降至 0.021 mg，提升约 497.17 倍；1 h 静态 Allan 方差记录的平均采样率为 200.000 Hz，gz 轴 ARW 为 0.005880 deg/sqrt(s)，BI 最小 Allan 偏差为 0.001145 deg/s；互补滤波在水平静止段 roll 标准差为 0.196 deg、pitch 标准差为 0.019 deg，并能在晃动后回到近水平稳定状态；GNSS 扩展测试中 NMEA 数据有效率为 82.11%。结果表明，该平台已具备传感器采集、标定补偿、姿态融合和扩展数据记录能力，但磁力计、气压计、功耗、成本和 AI 去噪的完整终稿指标仍需结合最终硬件实测继续补齐。
关键词：多传感器融合；ESP32；PCB 扩展板；传感器标定；姿态估计；AI 去噪
1 引言
1.1 研究背景
MEMS 传感器具有体积小、成本低、功耗低和易于嵌入式集成等优点，已广泛应用于移动机器人、无人机、可穿戴设备、智能车、姿态测量、导航定位和工业状态监测等场景。其中，惯性测量单元通常由三轴加速度计和三轴陀螺仪构成，可以输出载体的线加速度和角速度信息；磁力计可以提供地磁方向观测，用于航向角约束；气压计和 GPS 模块则可进一步提供高度和位置相关信息。通过多传感器融合，可以弥补单一传感器在噪声、漂移、环境敏感性和短时稳定性方面的不足，从而获得更稳定、更可靠的姿态和运动状态估计结果。
然而，低成本 MEMS 传感器在工程应用中通常存在明显误差。加速度计存在零偏、比例因子误差和轴间非正交误差；陀螺仪存在零偏漂移、随机游走和温度相关误差；磁力计容易受到硬铁和软铁干扰；PCB 布局、电源噪声和接口走线也会影响传感器数据质量。因此，完整的传感器系统设计不能只停留在读取原始数据，还应包含硬件集成、误差建模、标定补偿、滤波融合、实测验证和可复现归档等环节。
本课程论文以“从需求定义到产品交付”的工程闭环为目标，围绕 ESP32 多传感器融合扩展板展开设计。相比仅使用现成模块连线实验，自制 PCB 扩展板能够更好地体现传感器接口、电源去耦、总线共享、布局抗干扰和测试点设计等工程能力，也便于后续形成可复用、可复现、可迭代的课程项目资产。
1.2 问题提出
在实际使用中，直接将 MPU6050、HMC5883L 等低成本传感器接入 ESP32 后读取原始数据，通常无法直接满足高精度姿态估计要求。主要问题包括以下几个方面。
第一，传感器原始输出存在系统误差。加速度计在静止状态下三轴模长理论上应接近重力加速度，但由于零偏和比例因子误差，原始三轴数据的模长会偏离 1 g。磁力计在理想情况下采集到的三维磁场点云应近似分布在球面上，但硬铁干扰会导致点云中心偏移，软铁干扰会导致球体拉伸成椭球。陀螺仪即使在静止状态下也会存在非零输出，长时间积分后会造成姿态角漂移。
第二，单一滤波算法难以同时兼顾动态响应和稳态精度。互补滤波结构简单、计算量小，适合嵌入式实时运行，但参数选择会影响动态响应和噪声抑制效果。Madgwick 或 Mahony 滤波器能够利用四元数进行姿态更新，并结合加速度计和磁力计观测修正陀螺仪漂移，但仍需要根据实际数据进行参数调节。扩展卡尔曼滤波和误差状态卡尔曼滤波能够建立更加系统的预测与观测更新框架，但实现复杂度较高，对误差模型和噪声参数设置要求更高。
第三，硬件设计会直接影响数据质量。传感器电源脚附近是否放置去耦电容、I2C 总线是否合理上拉、磁力计是否远离 ESP32 芯片和 WiFi 天线、PCB 是否保留完整地平面和必要测试点，都会影响系统调试效率和最终测量结果。因此，本项目将 PCB 扩展板制作作为核心任务之一，而不是简单使用杜邦线连接模块。
1.3 本文贡献
本文围绕 ESP32 多传感器融合扩展板完成以下工作。
第一，设计一块可直接插接 ESP32-WROOM-32 开发板的 2 层 PCB 扩展板，集成 MPU6050、HMC5883L 和BMP280 气压传感器，并预留 GPS UART 接口、电源指示灯和关键测试点，形成适合课程实验和后续扩展的硬件平台。
第二，建立多类 MEMS 传感器误差补偿流程。针对加速度计，采用六位置标定和最小二乘求解方法估计零偏、比例因子和轴间误差；针对磁力计，采用椭球拟合实现硬铁和软铁补偿；针对陀螺仪，通过静止数据估计零偏，并使用 Allan 方差分析噪声特性。
第三，实现并对比多种姿态估计算法。本文设计互补滤波、Madgwick/Mahony 滤波和简化 ESKF，实现对 roll、pitch、yaw 姿态角的实时估计，并从精度、稳定性、计算量和实时性等方面进行对比。
第四，引入 AI 增强传感器算法。本文采用 1D-CNN 对 IMU 序列进行噪声去除，并与传统低通滤波或一阶卡尔曼滤波进行对比，以分析 AI 方法在传感器信号增强中的适用性和局限性。
2 系统硬件设计
2.1 总体架构
本系统由 ESP32-WROOM-32 开发板、多传感器扩展板、上位机数据记录与可视化程序三部分组成。ESP32 负责传感器初始化、数据采集、标定参数加载、姿态融合算法运行和串口数据输出；多传感器扩展板通过 2.54 mm 排针与 ESP32 开发板连接，板载 MPU6050、HMC5883L 和BMP280 气压传感器，并预留 GPS UART 接口；上位机通过串口接收数据，完成 CSV 记录、Python 可视化、标定参数求解和实验图表生成。
系统的数据流为：传感器原始数据首先经过驱动层读取，再经过标定层进行零偏、比例因子、软硬铁干扰等误差补偿，然后进入姿态融合层进行姿态角估计。对于 AI 增强算法，IMU 原始序列或标定后序列输入 1D-CNN 模型，输出去噪后的序列或辅助姿态估计量，最后与传统滤波结果进行对比分析。

2.3 PCB 原理图设计
本项目的 PCB 原理图设计围绕 ESP32 扩展接口、I2C 总线、电源去耦、传感器连接、GPS 接口、LED 指示和测试点展开。ESP32 开发板提供 3.3 V 和 GND 作为主要供电来源，所有传感器共用同一 I2C 总线，其中 SCL 推荐连接 GPIO22，SDA 推荐连接 GPIO21。I2C 总线上仅保留一组上拉电阻，推荐阻值为 4.7 kΩ，避免多个模块重复上拉导致等效阻值过低。

2.4 PCB 布局走线
PCB 布局需要兼顾机械兼容性、传感器性能和调试便利性。首先，扩展板尺寸应控制在 70 mm x 50 mm 以内，并保证 2.54 mm 排针位置与 ESP32 开发板匹配。其次，MPU6050 应尽量布置在 PCB 中央区域，以减少板边机械应力和手持扰动对加速度测量的影响。HMC5883L 对磁场干扰敏感，应远离 ESP32 芯片、WiFi 天线、电源区域、大电流走线和磁性元件。气压计应远离明显发热器件，避免温度变化影响气压测量。
信号完整性方面，I2C 走线应尽量短而清晰，SCL 和 SDA 走线不宜过长或绕行过多；传感器电源引脚附近应就近放置 0.1 uF 去耦电容；PCB 应尽量保持完整地平面，减少回流路径不连续造成的噪声问题。为提高调试效率，扩展板应预留 3.3 V、GND、SCL、SDA、MPU6050 INT 等测试点，便于用万用表、示波器或逻辑分析仪进行测量。

2.5 加工与焊接
2.6 PCB 实物设置差异与可实验性验证
本次扩展板实物调试中，PCB 板载器件和接口实现与课程给出的推荐报告模板或原始设计设想并非完全一致。实际板卡采用 ESP32 的 GPIO21/GPIO22 作为共享 I2C 总线，传感器地址扫描结果为 0x68、0x1E 和 0x76；其中 0x68 对应 MPU 系列六轴 IMU，WHO_AM_I 读数为 0x70，说明实际器件可能为 MPU6050 兼容型号或同系列 IMU；0x1E 对应 GY-273/HMC5883L 磁力计模块；0x76 的芯片 ID 为 0x58，可确认为 BMP280 气压计。上述差异不会改变本课程要求的核心实验对象，即 IMU、磁力计和气压计的多传感器采集、标定与融合验证。
为验证该 PCB 仍具备可实验性，本文补充了硬件连通性和传感器可用性测试。I2C 扫描能够同时发现 0x68、0x1E、0x76 三个设备；传感器冒烟测试中，加速度计、陀螺仪、磁力计数据均能随板子姿态变化产生合理响应，BMP280 也能返回有效芯片 ID。随后完成了 120 s IMU 静止采样，得到 6000 组数据，采样频率为 50.000 Hz，加速度模长均值为 1.025397 g，模长标准差为 4.275 mg；陀螺仪 X/Y/Z 三轴零偏分别为 0.221958 deg/s、0.982664 deg/s 和 -0.123877 deg/s。这说明当前板卡能够稳定输出可用于零偏估计、静态噪声分析和后续标定的数据。
针对磁力计可能受 ESP32 和周边器件干扰的问题，本文进行了 90 s 三维旋转采样和 WiFi 开关对比测试。旋转采样共获得 1800 组数据，估计硬铁偏置为 (63.0, -104.5, 32.5) raw count，三轴半径不均衡比为 1.139，中心化后半径变异系数为 0.0736，说明磁场点云整体覆盖较均衡，具备进一步椭球标定条件。WiFi 干扰对比中，WiFi 开启并扫描后磁场均值合成偏移约为 15.50 raw count，占关闭状态平均磁场模长的 3.23%；同时三轴标准差未增大，反而下降至关闭状态的 0.15-0.20 倍。因此，本次测试未观察到 WiFi 活动导致的明显随机噪声增强，GY-273 在当前安装位置受 ESP32 WiFi 射频活动的直接干扰不明显。
综上，虽然 PCB 实物设置与模板描述或原计划存在器件型号、模块形式和局部布局差异，但从地址扫描、寄存器识别、动态读数、静态采样和磁干扰对比结果看，当前板卡已经满足课程大作业所需的实验闭环：能够完成多传感器读取、静态误差统计、加速度计标定、磁力计标定、气压扩展验证以及后续姿态融合算法对比。后续报告中将把该差异作为工程调试事实说明，并以实测数据支撑系统可用性，而不将模板设计与实际实物混同。




PCB 设计完成后，需要在 KiCad 中完成 DRC 检查，确认不存在未连接网络、间距不足、封装错误和丝印遮挡等问题。随后导出 Gerber 文件、钻孔文件、BOM 清单和位置文件，并提交至 PCB 打样平台进行加工。收到 PCB 后，首先应检查板子外观、焊盘、孔位、丝印和排针位置是否与设计一致；焊接时建议先焊接排针和电源相关元件，再焊接传感器模块或芯片，最后焊接 LED、测试点等辅助部分。
焊接完成后，必须先进行断电检查，确认 3.3 V 与 GND 之间不存在短路。上电后使用万用表测量 3.3 V 电源是否正常，再连接 ESP32 串口进行 I2C 扫描，确认每个传感器地址能够被正确识别。只有在电源和总线通信正常后，才进入传感器驱动调试阶段。

3 传感器驱动开发
3.1 I2C 总线配置与多设备管理
ESP32 通过 I2C 总线读取 MPU6050、HMC5883L 和 BMP280 气压传感器的数据。I2C 总线采用主从结构，ESP32 为主设备，各传感器为从设备。程序初始化时首先配置 SCL 和 SDA 引脚、总线速率和超时时间，然后通过扫描地址确认设备在线状态。常见做法是遍历 0x03 至 0x77 地址范围，对每个地址发起写操作或读操作，若收到 ACK，则记录该设备地址。
在多设备管理中，需要注意不同传感器的初始化顺序、寄存器配置和采样频率。IMU 数据通常采样频率较高，磁力计和气压计采样频率相对较低。为了避免低速传感器影响高频姿态估计，可以采用定时任务或多速率调度策略。例如，MPU6050 以 200 Hz 采样，HMC5883L 以 50 Hz 更新，气压计以 25 Hz 更新，姿态融合算法以 100 Hz 或更高频率运行。

3.2 MPU6050 驱动实现
MPU6050 驱动主要包括设备唤醒、量程配置、采样率配置、低通滤波配置和原始数据读取。初始化时需要将电源管理寄存器从睡眠模式切换至正常工作模式，并根据实验需求配置加速度计和陀螺仪量程。加速度计量程越小，分辨率越高，但可测范围越窄；陀螺仪量程越小，对慢速姿态变化越敏感，但快速旋转时更容易饱和。因此本项目初始建议采用加速度计 ±2 g 或 ±4 g、陀螺仪 ±250 deg/s 或 ±500 deg/s 的配置，最终配置应根据实际测试动态范围确定。
MPU6050 每次读取应包含三轴加速度、三轴角速度和温度数据。原始寄存器数据需要根据量程系数转换为物理单位。转换后的加速度单位可采用 g 或 m/s²，角速度单位可采用 deg/s 或 rad/s。为了保证姿态算法的时间一致性，每组数据应记录时间戳，并计算相邻采样点之间的时间间隔 dt。

3.3 HMC5883L 驱动实现
HMC5883L 驱动主要包括工作模式配置、输出速率配置、量程配置和三轴磁场数据读取。磁力计的数据读取频率通常低于 IMU，因此在程序中可采用独立定时更新方式。读取到的原始磁场数据需要经过硬铁和软铁标定后才能用于航向角估计。若直接使用原始数据计算 yaw，容易受到周围磁性物体、电源电流和板载器件布局影响，导致航向角误差较大。
磁力计调试时，应首先在远离强磁干扰的环境下读取三轴原始值，观察旋转设备时三轴数据是否随姿态变化而合理变化。随后进行三维旋转采样，将原始数据导出为 CSV 文件，在上位机中进行椭球拟合，并将标定参数写回嵌入式程序。

3.4 BMP280/MS5611 驱动实现
BMP280 气压计通过 I2C 总线接入系统，地址为 0x76。本实验读取芯片 ID 得到 0x58，与 BMP280 常见 ID 0x58 一致，说明板载气压计模块焊接和通信正常。驱动程序读取 0x88 起始的温度、气压校准系数，并按照 BMP280 数据手册中的整数补偿公式计算温度与气压，再由气压相对变化换算相对高度。
若选用 BMP280 或 MS5611 作为气压传感器，驱动程序需要完成设备 ID 读取、补偿参数读取、采样配置、原始温度和气压读取以及物理量换算。气压数据可以用于估算相对高度变化，也可以作为系统扩展传感器展示多源数据采集能力。由于气压计对温度和气流敏感，实验中应尽量避免手指长时间接触器件或将其放在热源附近。
本项目选用 BMP280 作为气压扩展传感器，接口优先采用 I2C 方式，与 MPU6050、HMC5883L 共用 SCL/SDA 总线。

3.5 GPS NMEA 解析
GPS 接口作为挑战算法和系统扩展能力预留。若接入 NEO-6M 或 M8N 模块，ESP32 可通过 UART 接收 NMEA 语句，并解析其中的 UTC 时间、经纬度、速度、航向和定位状态。常用语句包括 GGA、RMC、VTG 等。GPS 更新频率通常为 1 Hz 或 5 Hz，明显低于 IMU 采样频率，因此 GPS 与 IMU 融合属于典型多速率融合问题。
若后续进行 GPS/IMU 融合实验，需要记录 GPS 时间戳、经纬度、速度和 IMU 时间戳，建立统一时间轴。若本项目最终仅预留 GPS 接口而未进行实物测试，应在论文中明确说明接口已预留、硬件具备扩展能力，但本次实验重点放在 IMU、磁力计和气压计数据融合上。
本项目保留 GPS UART 接口，并结合前期 GNSS 实验数据验证 NMEA 解析和轨迹记录流程；课程论文主线仍以 IMU、磁力计和气压计扩展为重点。
已有 GNSS 记录数据包含 1051 条原始样本，其中 863 条有效样本，有效率为 82.11%，平均 HDOP 为 2.651，卫星数为 4。该结果说明 UART-NMEA 数据链路和上位机解析流程具备复用基础。
4 标定与精度提升算法
4.1 加速度计 12 参数误差模型
加速度计的理想输出应与载体坐标系下的真实加速度一致，但实际传感器存在零偏、比例因子误差和轴间非正交误差。可将加速度计误差模型表示为：
a_c = M_a (a_r - b_a)
其中，a_r 为加速度计原始测量向量，b_a 为三轴零偏向量，M_a 为包含比例因子和轴间耦合关系的校正矩阵，a_c 为校正后的加速度向量。若展开为 12 参数模型，可将三轴零偏、三轴比例因子和轴间安装误差统一纳入待估参数。
在静止状态下，加速度计测得的是重力加速度在传感器坐标系下的投影。因此，无论传感器处于何种静止姿态，校正后的加速度模长均应满足：
a_c

= g


若使用 g 作为归一化单位，则目标为：
a_c

= 1


六位置标定通过将传感器分别放置在 +X、-X、+Y、-Y、+Z、-Z 六个姿态下，采集多组静态数据，并通过最小二乘方法求解误差参数，使校正后的模长尽可能接近 1 g。
4.2 六位置标定最小二乘求解
为进一步分析陀螺仪静态噪声与零偏稳定性，本实验新增陀螺仪 Allan 方差测试。实验数据来自 gyro_allan_20260616_205634.csv，板卡在整个采集过程中保持静止，ESP32 WiFi 关闭，采样率为 50.000 Hz，持续时间为 1799.980 s，共获得 90000 组样本。实验期间温度范围为 42.759°C 至 43.527°C，温度变化 0.768°C，说明测试环境温度相对稳定。
静态统计结果表明，陀螺仪三轴均存在非零零偏。其中 X/Y/Z 轴平均零偏分别为 0.228304 deg/s、0.964654 deg/s 和 -0.100939 deg/s，标准差分别为 0.052827 deg/s、0.071176 deg/s 和 0.060315 deg/s。Y 轴零偏明显大于 X、Z 两轴，若直接对角速度积分，将在长时间姿态估计中引入明显漂移，因此后续互补滤波、Mahony 等姿态融合算法需要先扣除陀螺仪零偏。

在六位置标定中，每个姿态下采集 N 组数据，并对每个姿态求均值，以降低随机噪声影响。设第 i 个姿态采集到的原始均值为 a_ri，对应的理想重力方向为 a_ti，则可建立残差：
r_i = a_ti - M_a (a_ri - b_a)
目标函数为：
J = sum_i ||r_i||²
通过最小化 J，可以得到加速度计的校正参数。若采用线性化形式，可将待估参数整理为向量 x，并构建矩阵方程：
A x = y
最小二乘解为：
x = (A^T A)^(-1) A^T y
当 A^T A 条件数较大时，可采用 QR 分解或 SVD 提高数值稳定性。标定完成后，应将标定参数保存到程序中，对实时采集的加速度数据进行补偿。

4.3 磁力计椭球拟合 DLS+SVD
磁力计在理想无干扰环境下，三轴磁场数据应分布在以原点为中心的球面上。然而，硬铁干扰会产生恒定磁场偏置，使球心发生平移；软铁干扰会改变磁场方向和幅值，使球面变为椭球。因此，磁力计标定的核心目标是将原始椭球点云校正为接近球形分布。
磁力计原始数据可表示为 m_r，校正模型为：
m_c = M_m (m_r - b_m)
其中，b_m 为硬铁偏置，M_m 为软铁补偿矩阵。椭球方程可写为：
x^T A x + d^T x + c = 0
将大量不同姿态下采集的磁力计数据代入椭球方程，可以使用直接最小二乘方法求解二次型参数。求得椭球中心后，可得到硬铁偏置；再通过矩阵分解方法得到软铁补偿矩阵，将椭球归一化为球体。实际实现中可使用 SVD 或特征值分解提高求解稳定性。
标定效果应通过 3D 散点图展示。标定前，磁力计点云通常表现为偏移椭球；标定后，点云应接近以原点为中心的球形分布。航向角计算也应在标定后进行，并结合加速度计姿态角进行倾斜补偿。

4.4 陀螺仪温度补偿与零偏估计
陀螺仪测量角速度，但在静止状态下也可能存在非零输出，该输出称为零偏。若不进行补偿，零偏经过积分会导致姿态角持续漂移。最基本的零偏估计方法是在设备静止状态下采集一段时间的角速度数据，并计算三轴均值：
b_g = mean(omega_r)
实时运行时，将原始角速度减去零偏：
omega_c = omega_r - b_g
如果传感器温度变化明显，还可以建立温度与零偏之间的拟合关系。例如，一阶温度模型可写为：
b_g(T) = kT + c
其中，k 和 c 可通过最小二乘法由不同温度条件下的静止采样数据求得。若实际测试中未进行温度控制实验，则本文可将温度补偿作为后续改进方向，重点完成静态零偏补偿和 Allan 方差分析。
陀螺仪静止采样包括 180 s 室温基线记录和 1 h Allan 方差记录，其中 Allan 数据文件 allan_raw_1h.csv 共 719946 行，时长 3599.725 s。
室温 180 s 静态基线中，gx、gy、gz 零偏均值分别为 0.655513 deg/s、1.054959 deg/s、-0.097135 deg/s，标准差分别为 0.044807 deg/s、0.059371 deg/s、0.054698 deg/s。
进行了温度漂移观察。冰袋降温与自然回温实验覆盖约 13.09 至 22.02 degC，gx 和 gz 随温度变化较明显，gy 相关性较弱；二次拟合后的分箱残差标准差分别为 0.009083 deg/s、0.003572 deg/s、0.006992 deg/s。
4.5 Allan 方差噪声特性分析
Allan 方差是分析惯性传感器随机误差特性的重要方法，可用于识别角随机游走、零偏不稳定性和速率随机游走等噪声项。对陀螺仪静止数据进行 Allan 方差分析时，首先需要采集足够长时间的角速度序列，然后按照不同聚类时间 tau 对数据分段求均值，并计算相邻均值差的平方平均。
Allan 方差定义可表示为：
sigma²(tau) = 1 / (2(M - 1)) sum_{k=1}^{M-1} (y_{k+1}(tau) - y_k(tau))²
其中，tau 为聚类时间，y_k(tau) 为第 k 段内的平均角速度，M 为分段数量。通过绘制 log-log 坐标下的 Allan 方差曲线，可以根据斜率识别不同噪声类型，并估计角随机游走和零偏不稳定性。
长时间静止采样文件为 allan_raw_1h.csv，记录时长约 60.00 min，平均采样率为 200.000 Hz。
Allan 方差曲线已由 fig_allan_curve_gz.png 生成，终稿排版时可插入该图。
以 gz 轴为例，tau=1 s 处 ARW 为 0.005880 deg/sqrt(s)，折算为 0.045544 deg/sqrt(min) 或 0.352780 deg/sqrt(hr)；BI 最小 Allan 偏差为 0.001145 deg/s，对应 tau=899.929 s。
5 多传感器融合
5.1 互补滤波
为满足课程要求中的“实时姿态显示”数据可视化任务，本项目进一步实现了 Python/Web 实时姿态板。电脑端程序 pc_mahony_serial_web.py 启动本地 Web 服务，并通过串口 raw REPL 将临时 MicroPython 程序发送至 ESP32 RAM；ESP32 端实时读取 MPU 系列 IMU 与 HMC5883L 磁力计，运行 Mahony PI 姿态融合算法，并将 roll、pitch、yaw、温度和更新频率回传至电脑端，网页端以 3D 板卡模型和实时曲线显示姿态变化。
该实现与单纯串口打印不同，传感器读取和 Mahony PI 融合计算均在 ESP32 端实时完成，Python 端只负责启动程序、接收实时姿态流并提供 Web 可视化界面。实验中网页显示的更新频率稳定在约 100 Hz，倾斜板卡时 3D 模型和 roll/pitch/yaw 曲线同步变化，可作为答辩现场实时演示材料。
本章在完成加速度计、磁力计和陀螺仪基础标定后，进一步实现姿态融合实验。实验采用四组典型运动状态：水平静止姿态、固定倾斜姿态、晃动后回到水平姿态、连续旋转或手动倾斜过程。每组实验均保存原始 IMU 与磁力计数据，并在电脑端离线运行两种姿态融合算法，以比较静态稳定性、动态响应和计算更新频率。
第一种算法为互补滤波。该算法利用陀螺仪积分获得短时间姿态变化，并用加速度计的重力方向和磁力计航向角对低频漂移进行修正。实验中互补系数取 0.98，因此短时间响应主要由陀螺仪决定，长期漂移由加速度计和磁力计缓慢拉回。
第二种算法为 Mahony 风格 PI 姿态融合。该方法在陀螺仪角速度积分基础上，引入由加速度计和磁力计构造的姿态误差，并通过比例项和积分项修正角速度积分漂移。与互补滤波相比，该方法对零偏和低频漂移具有更强抑制能力，但计算量略高。两种算法均使用 Allan 方差实验得到的陀螺仪零偏进行预补偿。
姿态融合实验共采集 16500 组样本，整体有效采样率为 49.561 Hz。离线运行时，互补滤波更新频率约 378048.4 Hz，Mahony 风格 PI 融合更新频率约 199629.3 Hz，二者均远高于 50 Hz 采样频率，说明在 ESP32 或上位机环境中均具备实时运行基础。

互补滤波利用陀螺仪短时动态响应好、加速度计长期稳定的特点，将两者进行频域互补。陀螺仪角速度积分可以获得短时间内平滑的姿态变化，但会随时间产生漂移；加速度计可以根据重力方向估计 roll 和 pitch，但容易受到线性加速度和振动干扰。互补滤波通过参数 alpha 平衡两类信息：
theta = alpha (theta_prev + omega dt) + (1 - alpha) theta_acc
其中，theta_prev 为上一时刻姿态角，omega 为陀螺仪角速度，dt 为采样时间间隔，theta_acc 为由加速度计计算得到的姿态角。alpha 越接近 1，系统越依赖陀螺仪积分，动态响应更平滑但漂移更明显；alpha 较小时，系统更依赖加速度计，长期稳定性更好但抗振性下降。
本项目中，互补滤波作为基准算法，用于与 Madgwick/Mahony 滤波和 ESKF 进行对比。其优点是结构简单、计算量小、易于在 ESP32 上实时运行；不足是对 yaw 角约束能力较弱，且参数需要根据实际数据调节。
5.2 Madgwick/Mahony 滤波器
Madgwick 滤波器采用四元数表示姿态，通过陀螺仪积分预测姿态，并利用加速度计和磁力计观测构造目标函数，通过梯度下降修正姿态误差。相比欧拉角积分，四元数能够避免万向节锁问题，适合嵌入式姿态估计。Madgwick 滤波器中的 beta 参数决定了观测修正强度，beta 过大可能导致姿态抖动，beta 过小则会削弱漂移修正能力。
Mahony 滤波器同样使用四元数表示姿态，但其核心思想是利用加速度计和磁力计观测方向与当前估计方向之间的误差构造反馈项，并通过比例积分结构修正陀螺仪零偏。Mahony 滤波器参数具有较直观的反馈意义，适合解释不同滤波算法的工程取舍。
本项目最终至少实现 Madgwick 或 Mahony 中的一种，并与互补滤波进行对比。对比指标包括静止状态姿态角标准差、动态倾斜响应速度、姿态更新频率和单次算法耗时。
当前实测验证以互补滤波为主，Madgwick/Mahony 作为后续同一数据集上的对比算法保留在实现计划中。
互补滤波采用 alpha=0.98，即 roll/pitch = 0.98 * 陀螺积分项 + 0.02 * 加速度计观测项；Madgwick/Mahony 参数将在同一测试序列上进一步整定。
5.3 倾斜补偿航向角
磁力计直接计算航向角时，只有在传感器保持水平的情况下误差较小。当设备存在 roll 和 pitch 倾斜时，磁力计测得的三轴磁场分量会受到姿态影响，必须进行倾斜补偿。倾斜补偿的基本思想是先利用加速度计或融合算法得到 roll 和 pitch，然后将磁力计数据旋转到水平坐标系，再计算 yaw。
设校准后的磁力计数据为 m_c = [m_x, m_y, m_z]^T，roll 为 phi，pitch 为 theta，则可通过旋转关系得到水平分量 m_xh 和 m_yh，再计算：
yaw = atan2(-m_yh, m_xh)
由于磁力计容易受到环境干扰，实际使用中应避免在靠近铁磁物体、电机、大电流线缆和强磁场的位置进行航向角测试。若磁场环境不稳定，应在论文中说明 yaw 角误差的主要来源，并将 roll、pitch 精度作为主要评价对象。

5.4 简化 ESKF 姿态估计
误差状态卡尔曼滤波将系统状态分为名义状态和误差状态。名义状态用于描述当前姿态、速度或位置估计，误差状态用于描述小量误差。对于姿态估计问题，直接在四元数空间进行线性化较复杂，而 ESKF 通过在误差状态中使用小角度扰动描述姿态误差，可以降低更新过程的复杂度。
本项目中的简化 ESKF 主要关注姿态误差和陀螺仪零偏。名义状态可表示为：
x = [q, b_g]
其中 q 为姿态四元数，b_g 为陀螺仪零偏。误差状态可表示为：
delta_x = [delta_theta, delta_b_g]
预测阶段使用陀螺仪角速度更新名义四元数，并根据过程噪声更新协方差矩阵。观测阶段利用加速度计提供重力方向观测，磁力计提供地磁方向观测，对姿态误差进行修正。更新完成后，将误差注入名义状态，并重置误差状态。
ESKF 的优势在于能够以统一概率框架处理传感器噪声和状态不确定性，并能解释姿态误差状态的物理意义。其难点在于雅可比矩阵、噪声协方差和观测模型的构建。若本项目最终实现简化版本，应重点展示模型假设、状态定义、预测更新流程和与传统滤波的实验对比。
简化 ESKF 状态采用名义四元数 q 与陀螺仪零偏 b_g，误差状态采用小角度姿态误差 delta_theta 与零偏误差 delta_b_g。
ESKF 过程噪声 Q 可由陀螺仪 Allan 方差和静态噪声统计初值设定，观测噪声 R 可由静止加速度计模长扰动和磁力计标定残差估计，终稿需结合完整对比实验调参。
由于当前已完成的可追溯姿态数据主要来自互补滤波序列，ESKF 定量对比暂作为后续补测项目；本文先给出状态设计和参数整定依据。
5.5 1D-CNN IMU 噪声去除
本节进一步开展 IMU 数据 AI 去噪实验。实验不重新采集额外数据，而是利用前述陀螺仪 Allan 方差实验中的长时间静止 IMU 数据构造训练样本，数据来源为 gyro_allan_20260616_205634.csv。输入特征为 ax、ay、az、gx、gy、gz 六通道时间窗口，采样率为 50.000 Hz，窗口长度为 64 个采样点，步长为 4 个采样点。
由于静止实验中真实角速度理论值为 0，加速度模长理论上应稳定，因此本实验采用自监督方式构造训练目标：先对原始六通道信号进行零相位滑动均值平滑，将其作为伪干净标签，再训练 1D-CNN 从含噪窗口中预测窗口中心的六通道去噪值。该方案不依赖外部高精度传感器，适合在课程实验条件下验证 AI 去噪方法的有效性。
对比方法包括四类：原始数据、低通滤波、一阶卡尔曼滤波和 1D-CNN。低通滤波用于体现传统平滑方法的效果；一阶卡尔曼滤波用于体现基于状态估计的递推去噪能力；1D-CNN 则利用局部时间窗口内六通道信号的相关性学习非线性去噪映射。评价指标包括标准差、RMSE、SNR，以及由加速度计计算得到的 roll/pitch 姿态角抖动。
1D-CNN 训练共进行 18 个 epoch，训练损失由 0.813700 下降至 0.280907，验证损失由 0.564495 下降至 0.277560，说明模型在静止 IMU 数据上能够有效学习到平滑后的信号特征。

6.1 实验平台与测试流程
本项目实验平台由 ESP32-WROOM-32 开发板、自制多传感器扩展板方案、上位机串口记录程序、Python 数据处理脚本和数据可视化脚本组成。已有可追溯实测数据主要来自 MPU6500/MPU6050 同类 IMU 标定与姿态实验、GNSS NMEA 记录实验，以及动态振动观测实验。测试流程包括静态基线采集、六位置加速度计标定、陀螺仪零偏统计、Allan 方差分析、互补滤波姿态输出、动态晃动响应观察和 GNSS 串口数据解析。

6.2 Spec 达成度分析
为验证第三类传感器 BMP280 的可用性，本项目补充进行了气压计静止噪声和高度变化实验。静止实验数据文件为 bmp280_static_20260617_084325.csv，共 1500 个样本；高度变化实验数据文件为 bmp280_height_change_20260617_084325.csv，共 900 个样本。采样过程中 BMP280 通过 I2C 总线读取温度和气压，并以实验开始阶段的平均气压作为参考气压计算相对高度。
静止实验中，平均气压为 100680.728 Pa，气压标准差为 2.072 Pa，峰峰值为 14.391 Pa；温度平均值为 31.308°C，温度标准差为 0.098°C，峰峰值为 0.420°C。由气压换算的相对高度标准差为 0.174 m，说明 BMP280 在静止条件下能够提供亚米级高度变化观测，但仍会受到气压噪声和环境扰动影响。
高度变化实验中，相对高度最小值为 -1.770 m，最大值为 -0.381 m，高度变化范围为 1.390 m；对应气压变化范围为 16.578 Pa。该结果说明 BMP280 能够感知手动抬升/放低或楼层微小变化带来的气压差，可作为系统中的高度变化辅助观测量。

6.6 AI 去噪实验结果
从六通道标准差看，1D-CNN 将 ax_g 标准差由 0.002246 降至 0.000433，将 gx_dps 标准差由 0.052568 deg/s 降至 0.008201 deg/s，将 gz_dps 标准差由 0.060222 deg/s 降至 0.009969 deg/s。与低通滤波相比，1D-CNN 在姿态角抖动和多个通道 SNR 上进一步改善；但其需要离线训练和更多计算资源，因此更适合作为精度增强模块或离线数据处理方法。
AI 去噪实验结果表明，四种方法中 1D-CNN 对静止 IMU 数据的噪声抑制效果最好。原始数据下 roll/pitch 姿态角抖动标准差分别为 0.1250° 和 0.1257°；低通滤波后下降至 0.0313° 和 0.0314°；一阶卡尔曼滤波后为 0.0521° 和 0.0528°；1D-CNN 进一步降低至 0.0249° 和 0.0243°。该结果说明 1D-CNN 能够利用六通道时间窗口中的局部相关性，比单通道递推滤波更有效地抑制随机噪声。
AI 去噪部分当前具备数据基础，但 1D-CNN 训练曲线和完整指标尚未归档。已完成的动态观测可用于构造噪声增强实验：静态基线 vibration_baseline_static.csv 中加速度模长标准差为 0.002393 g；敲击实验 vibration_table_tap_rerun.csv 中加速度模长标准差为 0.049189 g，约为静态基线的 20.56 倍；手机振动实验 vibration_phone.csv 中加速度模长标准差为 0.009407 g，约为静态基线的 3.93 倍。

6.7 功耗、频率与成本分析
实时姿态显示功能进一步补充了系统工程化验证：ESP32 端负责传感器采集和 Mahony PI 姿态融合，电脑端负责 Web 渲染和数据显示。该结构将嵌入式实时计算与上位机可视化分离，既能展示算法实时性，也便于答辩现场观察板卡倾斜时的姿态角变化。
BMP280 实验进一步证明当前 PCB 扩展板不仅完成 IMU 和磁力计集成，也完成了气压计传感器的硬件接入与数据验证。实测结果中 BMP280 静止气压标准差为 2.072 Pa，相对高度标准差为 0.174 m，高度变化实验可观测约 1.390 m 的相对高度变化，因此该模块可作为后续多传感器高度估计或楼层变化检测的扩展基础。
工程化频率指标测试表明，本系统 IMU 实际读取频率为 961.600 Hz，约为 200 Hz 指标的 4.81 倍；姿态融合实际更新频率为 365.227 Hz，约为 100 Hz 指标的 3.65 倍。说明当前硬件连接和算法实现具有足够实时性，可支撑后续姿态显示、数据记录和多传感器融合应用。
频率方面，IMU 原始数据长时间记录已达到平均 200.000 Hz，满足传感器采样率目标。姿态输出序列受串口输出格式和记录脚本影响，当前记录频率约 20 Hz，不能直接代表算法内部最高运行频率。若要证明姿态更新频率 >= 100 Hz，应在固件中单独统计滤波循环周期，或降低串口输出负担后重新记录。

6.8 问题分析与改进方向
硬件实物与模板设计存在差异是本项目调试中的主要工程事实之一。本文不将该差异简单视为失败，而是通过 I2C 扫描、传感器冒烟测试、IMU 静止采样、磁力计旋转采样和 WiFi 干扰对比逐项验证实物板卡的实验可用性。结果表明，当前 PCB 虽与推荐模板不完全一致，但能够稳定支撑课程要求的传感器驱动、标定和融合算法验证。后续改进可进一步统一器件丝印、原理图标注和报告描述，并使用固定夹具重复 WiFi 干扰测试以降低姿态微小变化带来的均值偏移。
当前实验暴露出三个需要在终稿或后续版本中重点处理的问题。第一，互补滤波在动态晃动后存在约 2-3 deg 的 roll 残余偏置，说明启动零偏估计和固定 alpha 参数对复杂运动还不够稳健。后续可加入静止检测、在线零偏更新和自适应滤波权重。第二，温度补偿实验虽然覆盖 13.09 至 22.02 degC，但温度跨度和环境控制仍有限，拟合结果只能作为初步观察，不能替代标准温箱标定。第三，AI 去噪已有噪声场景数据，但缺少高精度真值，后续应引入参考传感器或设计可重复激励平台，避免仅用平滑结果作为监督目标造成评价偏差。
对于 PCB 实物相关问题，终稿需要补充真实调试记录，例如 I2C 地址扫描是否成功、某个传感器是否焊接不良、上拉电阻是否重复、3.3 V 电源是否稳定等，并按“现象、定位、原因、解决、复测结果”的格式写入。
7 总结与展望
7.1 工作总结
本文围绕 ESP32-WROOM-32 设计并实现了一种多传感器融合扩展板方案，完成了从项目 Spec 定义、硬件原理图设计、PCB 布局走线、传感器驱动、标定算法、姿态融合算法到 AI 增强去噪方案设计的完整流程。硬件方面，系统以 2.54 mm 排针兼容 ESP32 开发板，集成 MPU6050、HMC5883L 和 BMP280 气压传感器，并预留 GPS UART 接口，为后续多速率融合和轨迹实验提供扩展条件。算法方面，本文建立了加速度计、磁力计和陀螺仪的误差补偿流程，并以互补滤波完成姿态估计实测验证。
实验结果表明，加速度计六位置标定能显著降低模长误差，平均误差由 10.401 mg 降至 0.021 mg；陀螺仪 1 h 静态记录达到 200.000 Hz 平均采样率，并得到 gz 轴 ARW 和 BI 指标；互补滤波在水平静止段具有较好的 roll/pitch 稳定性，但动态晃动后仍存在小幅残余偏置。GNSS 扩展数据说明 UART-NMEA 解析链路可复用，但普通单点定位精度不足以作为高精度姿态参考。
7.2 不足与改进方向
本项目仍存在若干可改进方向。首先，低成本 MEMS 传感器本身噪声较大，姿态精度受标定质量、安装方式和参考测量工具精度影响明显。后续可引入更高精度 IMU 或外部运动捕捉设备作为参考基准。其次，磁力计对环境干扰敏感，yaw 角精度会受到周围铁磁物体和电流走线影响，终稿应补充完整椭球标定点云和航向角对比实验。第三，简化 ESKF 的噪声协方差参数需要结合 Allan 方差结果进行更系统的整定，并与互补滤波、Madgwick/Mahony 在同一数据集上比较。第四，1D-CNN 去噪的训练数据和真值构造仍是难点，后续可采集更多真实场景数据，或使用高精度参考传感器建立更可靠的监督数据集。
7.3 个人收获与反思
通过本项目，我对传感器系统的理解从单一模块读数扩展到了“硬件、驱动、标定、融合、验证”一整条链路。刚开始容易把精度提升理解为更换算法，但实际实验表明，PCB 布局、电源稳定性、采样时间戳、标定姿态覆盖范围和数据记录方式都会影响最终结果。六位置标定让我直观看到系统误差补偿的价值：同样的传感器，在建立误差模型并写入校正矩阵后，模长误差可以明显下降。姿态融合实验也提醒我，滤波参数不能只看公式，需要结合真实动态过程调节；静止时稳定并不代表晃动后一定能完全回零。后续如果继续完善该项目，我会优先补齐 PCB 实物调试照片、磁力计标定数据、功耗和成本表，并在同一批原始数据上复现实验曲线，使论文结论更完整、更可追溯。
