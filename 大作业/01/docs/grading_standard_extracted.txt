一、设计目的与要求
1. 核心目的
《传感器与检测技术》课程的最终综合考核，旨在将本学期所学的传感器驱动、误差建模、标定技术、滤波算法、AI 增强、PCB 设计等知识融会贯通，完成一个从需求定义到产品交付的完整工程闭环。通过本设计，学生将掌握：
产品级系统设计方法：先定义规格指标，再进行软硬件开发
多传感器融合系统的硬件集成与信号完整性设计
从互补滤波到 ESKF 的全系列姿态融合算法工程实现
AI 增强传感器算法的边缘端部署与性能量化
数字化资产沉淀方法：所有设计可复用、可复现、可迭代
2. 硬性要求
设计一块可直接插在 ESP32-WROOM-32 开发板上的扩展板，采用 2.54mm 排针兼容设计
板载至少2 种必修传感器：MPU6050（六轴 IMU）、HMC5883L（三轴磁力计）
鼓励集成选修传感器：MS5611 气压计、Ublox M6N/M8N GPS 模块
算法必须包含至少 2 种传统滤波算法和1 种 AI 增强算法
所有性能指标必须通过实测验证，答辩时用数字和图表说话
所有设计文件、代码、数据、报告全部上传，形成可复现系统
二、系统设计要求
1. 硬件设计要求（ESP32 扩展板）
1.1 基础规格
尺寸限制：≤70mm×50mm（适配嘉立创打样尺寸，标准 2 层板）
供电：通过 ESP32 开发板 5V/3.3V 供电，无需外部电源
接口：全部采用 2.54mm 排针，与 ESP32 开发板引脚一一对应，I²C 总线共享(SCL/SDA)  ，所有传感器挂同一 I²C 总线 ，|GPS 接口|4-pin 2.54mm 排针(VCC/GND/TX/RX)|外接 NEO-6M,用杜邦线连 ，|LED 指示|至少 1 个电源指示 LED ，绿色,串 1kΩ电阻。
布局建议：MPU6050 放板中央，减少边缘应力 ，距板边 ≥ 5mm ， ，HMC5883L远离 ESP32，避免ESP32芯片/WiFi天线的磁干扰距，远离发热元件，温度影响气压读数 ，GPS 排针在板边缘，方便连线                   朝外，I²C 上拉电阻一组就够(多个会并联降阻)，4.7kΩ × 2(SCL/SDA 各一个)
1.2 必修传感器电路
MPU6050 六轴 IMU：
通信接口：SPI（优先）或 I2C
必须包含 0.1μF 去耦电容、电源滤波电路
预留中断引脚，用于数据就绪触发
HMC5883L 三轴磁力计：
通信接口：I2C
必须包含去耦电容和上拉电阻
布局远离电源、电机等强干扰源
1.3 选修传感器电路（鼓励至少选 1 种）
MS5611 或BMP280气压计：SPI 接口，高精度气压高度测量
Ublox M6N GPS 模块：UART 接口，预留天线接口
电源管理：可选 3.3V LDO，为传感器提供干净电源
1.4 信号完整性要求（对应第六讲内容）
所有传感器电源引脚必须就近放置 0.1μF 陶瓷去耦电容
模拟信号走线尽量短，避免与数字信号走线交叉
完整的地平面设计，分割数字地和模拟地
预留测试点，方便调试和信号测量
2. 算法设计要求
2.1 基础算法（所有组必须完成）
传感器标定算法：
加速度计六位置标定（12 参数模型），零偏 50mg → 2mg(25×)
磁力计椭球拟合标定（硬铁 / 软铁补偿），航向 ±15° → ±2°(7×)
陀螺仪零偏校准与 Allan 方差分析，零偏漂移降 10×
传统姿态融合算法（至少实现 2 种）：
互补滤波
Mahony 滤波
Madgwick 滤波
扩展卡尔曼滤波（EKF）
性能对比分析：
对比不同算法的姿态精度、计算复杂度、CPU 占用率
量化每种算法带来的精度提升幅度
数据可视化（必做）
标定前后精度对比表    Python matplotlib|误差降低倍数
Allan 方差曲线      Python allantools|ARW/BI 标注
磁力计 3D 散点(校准前后) Python mplot3d   椭球→球
实时姿态显示         串口 + Python / Web 倾斜板子看角度变化
GPS 轨迹叠加       Python folium     户外测试轨迹
2.2 进阶算法（80 分以上必须完成）
误差状态卡尔曼滤波（ESKF）：
基于李群李代数 SO (3) 的姿态表示
实现 IMU 预积分与误差状态更新
目标姿态精度：≤±0.2°（静态）
AI 增强传感器算法（至少实现 1 种）：
1D-CNN IMU 噪声去除：对比传统低通滤波的 SNR 提升 dB 数
一阶卡尔曼滤波与 1D-CNN 的混合去噪架构
目标：纯惯导漂移从 10m/min 降低至≤3m/min
2.3 挑战算法（90 分以上可选）
多速率传感器融合：GPS 1Hz + IMU 200Hz 异步状态更新
LSTM GPS 失锁预测：当 GPS 信号丢失时，用 LSTM 预测轨迹
TLIO/DeepVIO 核心模块复现：基于深度学习的紧耦合惯导里程计
多传感器时间同步：实现 IMU、磁力计、GPS 的微秒级时间对齐
三、设计任务与阶段安排
第一阶段：期末设计硬件规格书（Spec）编写（第 15 周）
核心要求：没有写清楚 Spec 的设计，不允许开始打样
明确系统的四大核心指标，每个指标必须有具体数字：
表格
指标类型
目标值
验证方法
精度指标
静态姿态精度≤±0.2°
动态姿态精度≤±0.5°
纯惯导漂移≤3m/min
高精度倾角仪基准对比
GPS 轨迹对比
带宽指标
姿态更新频率≥100Hz
传感器采样率≥200Hz
示波器测量中断频率
功耗指标
系统总功耗≤100mA@3.3V
万用表测量电流
成本指标
单块 PCB+BOM≤50 元
嘉立创报价 + BOM 清单
编写详细的硬件设计方案：原理图框图、引脚分配、传感器选型理由
编写详细的算法设计方案：算法流程图、状态变量定义、误差模型
第二阶段：PCB 设计与打样（第 16 -17周）
使用KiCad完成原理图和 PCB Layout 设计 2.5cm
鼓励使用AI 辅助设计：用 Cursor/Claude 辅助生成原理图，用 AI 辅助布线
完成 DRC（设计规则检查），确保没有电气错误
生成 Gerber 文件和 BOM 清单，在嘉立创下单打样（5 片，约 30 元，5-7 天到货）
第三阶段：硬件焊接与调试（第 17-18 周 ）
焊接所有元器件，进行硬件通电测试
逐个调试每个传感器，确保能正常读取数据
测量传感器的噪声水平和信号质量，验证信号完整性设计
记录焊接和调试过程中遇到的所有问题和解决方案
第四阶段：算法开发与部署（第 18 周 ）
实现所有传感器的驱动程序，完成数据采集
实现传感器标定算法，完成标定并验证标定效果
实现传统姿态融合算法，进行性能对比
实现 ESKF 和 AI 增强算法，量化精度提升幅度
将所有算法部署到 ESP32 上，确保实时运行
第五阶段：性能测试与指标验证（第 18 周 ）
按照 Spec 中定义的验证方法，逐项测试所有性能指标
记录所有测试数据，生成对比图表
分析实测值与目标值的差异，提出改进方案
录制系统演示视频，展示系统的功能和性能
第六阶段：答辩准备与资产沉淀（第 19 周 ）
准备答辩 PPT，重点展示 Spec 达成度、算法原理、测试结果
整理所有设计文件，上传至个人 GitHub 仓库
撰写详细的设计报告，包含需求分析、设计方案、测试结果、总结反思
