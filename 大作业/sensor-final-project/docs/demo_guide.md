# 项目现场演示指南

本项目的演示目标是证明：传感器扩展板能够实时采集多传感器数据，ESP32 端能够运行姿态融合和 15 维松耦合 ESKF，电脑端能够实时显示、保存数据，并能观察到融合算法对 GPS 抖动和 IMU 漂移的抑制效果。

## 一、演示前准备

1. 连接 ESP32 到电脑，确认端口为 `COM4`。
2. 关闭 Thonny Shell 或其他占用串口的软件。
3. 确认 ESP32 已写入实时程序：
   - ESP32 端程序：`firmware/fusion/esp32_eskf_15d_realtime_main.py`
   - 安装脚本：`firmware/tools/pc_install_esp32_eskf_15d.py`
4. 打开电脑端实时网页程序：
   - `firmware/fusion/pc_eskf_15d_serial_web.py`
5. 浏览器访问：
   - `http://127.0.0.1:8767`

电脑端网页会自动读取 COM4，保存实时 CSV，并显示姿态、GPS 状态、ENU 轨迹、滤波一致性指标。网页图表使用本地 `firmware/fusion/assets/echarts.min.js`，演示时不需要联网。

## 二、推荐演示流程

### 1. 硬件连接与传感器状态

先展示实物板和传感器模块，说明当前硬件包含：

- ESP32 主控
- MPU6500/MPU6050 兼容 IMU
- HMC5883L/GY-273 磁力计
- BMP280 气压计
- GPS6MV2/NEO-6M GPS 模块

网页中如果显示 GPS 已定位、卫星数、HDOP、板上更新率，说明 ESP32 正在实时采集数据。

### 2. 静止状态验证

将板子静止放在桌面上，观察网页：

- `水平速度` 应接近 `0 m/s`
- `融合位置 ENU` 不应持续发散
- 橙色原始 GPS 轨迹可能会轻微抖动
- 蓝色 ESKF 融合轨迹应比原始 GPS 更稳定

这一段用于证明：低速步行 15 维松耦合 ESKF 加入了静止检测、零速更新和位置保持约束，不会把 GPS 静止漂移直接当成真实运动。

### 3. 姿态融合验证

轻轻倾斜板子并观察网页的姿态板和姿态角曲线：

- 左右翻转时，`横滚 Roll` 变化明显
- 前后抬起时，`俯仰 Pitch` 变化明显
- 水平旋转时，`航向 Yaw` 变化明显

这一段用于证明：ESP32 端正在利用陀螺仪、加速度计和磁力计进行实时姿态融合。

### 4. GPS/IMU 融合轨迹验证

如果环境允许，将板子带到开阔位置缓慢移动，观察轨迹对比图：

- 橙色：原始 GPS 轨迹
- 蓝色：ESKF 融合轨迹
- 红点：当前位置

移动时 `East/North` 会发生变化；停止后，速度应回到接近 0，轨迹不应继续明显漂移。

### 5. 数据保存验证

演示过程中，电脑端会自动保存 CSV 到：

`data/fusion_comparison/eskf_realtime/`

可以现场打开最新 CSV，说明网页显示不是静态图片，而是来自 ESP32 串口实时输出的数据。

## 三、建议录制 demo.mp4 的内容

建议录制 2 到 3 分钟视频，包含以下镜头：

1. 板子实物和 USB/GPS 连接状态。
2. 浏览器打开实时融合看板。
3. 静止状态下，展示原始 GPS 与 ESKF 轨迹差异。
4. 手动倾斜板子，展示 Roll/Pitch/Yaw 实时变化。
5. 缓慢移动板子，展示 ENU 轨迹变化。
6. 打开自动保存的 CSV 文件，展示实时数据记录结果。

## 四、现场口述示例

本项目不是离线画图展示，而是在 ESP32 上实时读取 IMU、磁力计和 GPS 数据，并在板端运行 Mahony 姿态融合和适配低速步行场景的 15 维松耦合 ESKF。电脑端网页只负责接收串口数据、实时可视化和保存 CSV。

静止时，低成本 GPS 会存在米级漂移，IMU 积分也会产生漂移。因此本项目在 ESKF 中加入了静止检测、零速更新和弱位置保持约束。可以看到原始 GPS 轨迹仍会轻微抖动，但融合轨迹和水平速度更加稳定，符合静止状态的真实物理情况。

当手动倾斜板子时，Roll、Pitch、Yaw 曲线实时变化，说明姿态融合算法在板端运行。移动板子时，ENU 轨迹随运动变化，停止后速度逐渐回到接近 0，说明 GPS/IMU 融合算法能够用于低速步行场景。

## 五、GPS 异常时的备用验证

如果现场 GPS 暂时没有定位，可以运行快速诊断脚本：

`firmware/tools/pc_gps_quick_diagnose.py`

该脚本不会修改 ESP32 flash，只会临时读取 GPS 原始 NMEA，检查是否存在有效的 GGA/RMC 定位语句。若现场遮挡严重，可使用已采集的户外数据和 folium 轨迹图作为备用展示材料。
