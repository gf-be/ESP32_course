# 实验四 MPU6050/MPU6500 标定实验提交说明

本目录为实验四最终提交内容，按实验三最终提交结构整理。报告依据《实验四指导手册 MPU6050标定版》重新撰写，并结合本人实际使用的 MPU6500 兼容模块进行说明。

## 目录结构

- `report_lab4_final.pdf`：最终实验报告 PDF。
- `report_lab4_final.tex`：最终实验报告 LaTeX 源文件。
- `code/`：ESP32-S3 与 MPU60x0/MPU6500 通信、采集、标定和姿态估计相关代码。
- `data/`：实验实测 CSV 数据，包括六位置标定、振动观察、陀螺仪温度补偿、Allan 方差和互补滤波姿态数据。
- `assets/`：报告中引用的结果图表。
- `*_result.md`：各实验阶段的数据分析过程和结果记录。
- `requirements.txt`：电脑端数据分析脚本所需 Python 依赖。
- `实验四GitHub提交内容.md`：最终提交内容清单和可追溯说明。

## 实验完成情况

本实验完成了 MPU60x0 初始化、基础读取、动态误差体验、六位置加速度计标定、陀螺仪温度补偿、Allan 方差实测和互补滤波姿态估计。实际模块身份寄存器为 `WHO_AM_I = 0x70`，因此报告中说明其为 MPU6500 或兼容模块；其主要 I2C 寄存器与指导手册中的 MPU6050 实验流程兼容。

主要结果如下：

- 六位置加速度计标定后，平均模长误差由 `10.401 mg` 降至 `0.021 mg`。
- 陀螺仪温度补偿数据覆盖 `13.09--22.02 degC`，三轴二次拟合分箱残差均小于 `0.05 deg/s`。
- Allan 方差使用约 1 小时静止数据，`gz` 轴 ARW 为 `0.352780 deg/sqrt(hr)`，BI 为 `0.001145 deg/s`。
- 互补滤波完成连续倾斜与晃动回正验证。

直接阅读 `report_lab4_final.pdf` 即可查看最终报告。若需要复查数据来源，可查看 `data/` 中对应 CSV，代码入口在 `code/main.c`，分析结果记录在各 `*_result.md` 文件中。
